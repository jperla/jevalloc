Server-sim is a synthetic request server. All allocation paths use xmalloc. parse_request_buffer and assemble_response_buffer create request temporaries freed during the operation. create_session_state holds session state across requests until a load drop. insert_cache_index creates retained entries that are never freed. In the mixed tier, store_request_payload uses request TTL data at one allocation site: zero expires during the operation, a positive TTL holds it until the load drop, and a large TTL retains it permanently. Sizes overlap across lifetimes.
