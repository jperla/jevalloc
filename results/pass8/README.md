# Pass 8 evidence

[../../RESULTS.md](../../RESULTS.md) is the reader-facing report;
[../../CODEX-REPORT.md](../../CODEX-REPORT.md) records the work and corrections.

- `pure/`: site-pure matrix, five repetitions per variant, inference audit and truth.
- `real/<workload>/`: trace-derived site summaries, all greedy-search trials,
  independent five-run headroom gate, selected tables and inference audit.
- `pass8-regression.*`: complete regression aggregate and independent inference audit.
- `tests.json`, test logs, `hybrid-integration.json`, and `instrument/`: correctness,
  rule/protocol tests, allocator integration tests and instrumentation gate.
- `builds/`: pinned source and measured binary hashes, with source-build logs.
- `search.md`, `details.md`, `accuracy.json`, `wrong-priors.json`: readable search,
  ranges/costs, and wrong-prior evidence generated by `tools/pass8_report.py`.
- `redis-mesh-average-idle/`: superseded pilot, excluded from final findings.
  `headroom-average-idle.py` preserves its original runner. See its archive note.
- `validation.json`: independently recomputed search decisions/gates, completeness
  and measured-library checks (`tools/pass8_validate.py`).
- `search-intervals.*`: all 525 retained search-trial intervals and their independent
  zero-overlap inference audit.
- `history.md`: the committed report before pass 8.

Raw stdout/stderr, traces, decision logs, replay schedules and caches remain on
the test machine under `~/jevalloc/src-tree/results/`, at paths recorded in the
matrices. The local evidence set omits those bulky files; final oracle/search
tables are included. Paths in copied instrumentation and correctness aggregates
still refer to their original remote locations. Audit hashes cover the exact
matrix bytes. Source and binary fingerprints describe each measured block.

All headline real-program measurements use final idle RSS. The six real cases
with one idle phase were measured before the runner's average-to-final correction;
the two definitions are identical for every observation in those blocks. The
two-cycle Mesh case was rerun completely with the corrected runner. Search trials
are training data; final five-run gates are independent. Failed headroom gates
prevent model evaluation, so empty real-site model output is intentional.
